# UI/UX Pro Design System Skill

This skill defines the visual architecture, typography, micro-interactions, and density standards for building state-of-the-art web dashboards.

## Core UI/UX Rules

### 1. Palette & Surface Contrast
- **Background Base**: Deep desaturated navy/charcoal (`#0B0E14`).
- **Cards & Elevators**: `#12141C` with hairline 1px borders (`#1E222D`).
- **Muted Surfaces**: `#1A1D26`.
- **Interactive Accent**: Brand Violet/Indigo (`#6366F1`) for primary actions, navigation indicators, and focus states.

### 2. Strict Semantic Encoding
- **Passed / Success (`#3FB27F`)**: Muted emerald green strictly for passing scores (>40%), verified biometrics, and online gateways.
- **Failed / Danger (`#E5484D`)**: Muted red strictly for failed assessments, severe violations, and terminated sessions.
- **Warning / At-Risk (`#E5A54B`)**: Amber for gaze shifts, tab switches, and setup alerts.

### 3. Typography & Data Formatting
- **Headings & Body**: Clean geometric sans-serif (`-apple-system`, `BlinkMacSystemFont`, `Inter`, `Segoe UI`).
- **Numeric Data**: Monospace font (`font-mono`) for all scores (`85/100`), percentages (`85%`), USNs (`1MS21CS042`), timestamps (`14:32:05`), durations (`60 min`), and flag counts.

### 4. Non-Generic Metric Layouts
- **Hero Stat Card**: Highlight the primary metric (Cumulative Score / Pass Rate) with a progress bar or distribution visual.
- **Slim Secondary Row**: Group remaining metrics in a compact, high-density row.

### 5. High-Density Functional Tables
- Integrated live title search, status filter tabs (`ALL`, `PASSED`, `FAILED`, `FLAGGED`), pagination controls, and proctoring integrity indicators.
